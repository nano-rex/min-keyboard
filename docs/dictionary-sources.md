# Dictionary sources

All runtime dictionaries live in `android/app/src/main/assets/` and are shared by
the Android and Linux editions. They are generated by
`tools/build_dictionaries.py` (frequency ranking, Japanese and Korean lexicons)
and `tools/build_lexicon.py` (merging pinyin sources).

| Asset | Contents | Built from |
| --- | --- | --- |
| `english_words.txt` | ~74,000 words, most frequent first | FrequencyWords `en_full.txt`, filtered by the SCOWL list `/usr/share/dict/american-english` |
| `malay_words.txt` | ~50,000 words, most frequent first | FrequencyWords `ms_full.txt` (words seen at least 3 times) |
| `pinyin_lexicon.tsv` | pinyin → Simplified and Traditional candidates, ranked by frequency; 4th column is the top word's frequency, used to segment whole sentences | CC-CEDICT, Fcitx5 Pinyin Zhwiki, OpenCC, re-ranked with jieba `dict.txt` and FrequencyWords `zh_cn_full.txt` |
| `japanese_lexicon.tsv` | hiragana reading → kanji candidates, in SKK's curated order; 3rd column ranks readings for completion | SKK-JISYO.L (okuri-nasi entries), FrequencyWords `ja_full.txt` |
| `korean_lexicon.tsv` | romanization → Hangul words, most frequent first | FrequencyWords `ko_full.txt`, romanized by the build script |
| `*_shortcuts.tsv` | hand-written abbreviations and phrases | this project |

## Rebuilding

Download the sources into a folder of your choice, then run from the repository root:

```bash
python3 tools/build_dictionaries.py english --frequency en_full.txt --spelling /usr/share/dict/american-english
python3 tools/build_dictionaries.py malay --frequency ms_full.txt
python3 tools/build_dictionaries.py chinese --jieba dict.txt --frequency zh_cn_full.txt \
    --opencc-characters TSCharacters.txt --opencc-phrases TSPhrases.txt
python3 tools/build_dictionaries.py japanese --skk SKK-JISYO.L --frequency ja_full.txt
python3 tools/build_dictionaries.py korean --frequency ko_full.txt
```

The FrequencyWords files are at
`https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/<lang>/<lang>_full.txt`.
After rebuilding, run the engine tests: `./android/gradlew -p android :app:testDebugUnitTest`
and `python3 -m unittest discover -s linux`.
